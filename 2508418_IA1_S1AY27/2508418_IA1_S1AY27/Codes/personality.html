LLMs: Tool, Not a Crutch

Large language models such as ChatGPT, Claude and Copilot can support students, but they should not replace independent thinking. To me, using an LLM as a tool means remaining responsible for understanding the work.

As a Computer Science student, I can use an LLM to explain difficult concepts, provide examples, help identify possible programming errors and assist with brainstorming.

However, LLMs can produce inaccurate information or incorrect code. Therefore, I should verify important information using lecturers, textbooks, documentation and reliable sources.

The best use of an LLM is therefore as a learning assistant. It can support my learning, but it should not become a replacement for my own effort and understanding.
